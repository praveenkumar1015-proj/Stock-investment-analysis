# 📊 Investment Analysis of NIFTY 500 Stocks

## 📌 Project Overview

This project focuses on analyzing NIFTY 500 stock market data to identify growth opportunities, investment-worthy stocks, industry trends, and risk-return relationships.

The project combines **Excel, MySQL, Python, SQL, and Power BI** to perform data cleaning, exploratory data analysis (EDA), statistical analysis, and dashboard visualization for investment decision-making.

---

# 🎯 Project Objectives

- Collect and organize NIFTY 500 stock market data.
- Clean and preprocess stock data for analysis.
- Store stock information in a MySQL database for efficient querying.
- Perform Exploratory Data Analysis (EDA) and statistical analysis.
- Identify top growth and investment-worthy stocks.
- Analyze sector-wise and industry-wise market trends.
- Visualize insights through an interactive Power BI dashboard.
